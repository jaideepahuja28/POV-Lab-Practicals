# POV-Lab-Practicals
## Authored by: Jaideep

### This repository hosts the documents of all the practicals of Virtualization Lab, covered as per the syllabus.

* Course Title: Virtualization Lab
* Course Code: BCA-379A
* Total Practicals: 12
* Practicals Covered: 5

# List Of Practicals:
1. Enable BIOS Virtualization (Intel VT-x / AMD-V) and check virtualization support on host.
2. Install VirtualBox/VMware Workstation on Windows/Linux (32-bit & 64-bit).
3. Create and Configure a Virtual Machine with Operating System Installation.
4. Configure Virtual Machine Resources (CPU, RAM, Storage) and Virtual Hard Disk & Shared Folder.
5. Configure Virtual Networking in VMware/VirtualBox.
6. Clone Virtual Machine, Export/Import VM Images & Snapshot Management.
7. Install and Configure Remote Desktop (RDP) Services on Windows Server.
8. Deploy and Access Remote Applications using RemoteApp & RD Web Access.
9. Configure Remote Desktop Client for Virtual Desktop Access.
10. Introduction to VMware vSphere, ESXi & vCenter — Create VM on ESXi Server.
11. Configure Hyper-V and Create Virtual Machine.
12. Install & Use VM Performance Monitoring Tools (Nagios / Zabbix).
